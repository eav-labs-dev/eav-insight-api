# Code of Conduct

## Purpose

EAV Labs repositories should remain professional, respectful, and focused on practical software engineering.

## Standards

Expected behavior:

- communicate respectfully
- give constructive feedback
- keep issues and pull requests focused
- document decisions clearly
- avoid misleading claims about project status or contributors

Unacceptable behavior:

- harassment or abusive language
- intentionally misleading project activity
- sharing credentials, secrets, or private information
- destructive or malicious contributions

## Enforcement

As this is a personal portfolio project, the repository owner may close issues, reject pull requests, or remove content that does not meet these standards.
